# mapa-interactivo-psicologia-UADE
Mapa interactivo del plan de estudios de la Licenciatura en Psicología de UADE (Plan 7816, 2016). Sirve para ver de un vistazo qué materias hay, cuáles dependen de cuáles y cómo venís avanzando en la carrera.  Es un proyecto hecho por y para estudiantes. No es una página oficial de UADE y no tiene relación con la universidad.
